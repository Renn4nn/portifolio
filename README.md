# Renan Vieira — portfólio

Frontend em React e Vite, sem API.

## Desenvolvimento

```sh
npm install
npm run dev
```

Acesse http://localhost:4500. Para gerar o site estático: `npm run build` (saída em `dist/`).

Os projetos ficam em `src/projects.js`, a apresentação em `src/App.jsx` e os estilos em `src/style.css`. Imagens em `public/assets/`.

Carrosséis com Embla Carousel e troca automática a cada 6,5 segundos. As telas vizinhas permanecem visíveis durante as transições; há navegação por setas, indicadores e toque. Respeitam movimento reduzido e interrompem a rotação quando fora da tela ou com imagem ampliada.

Estilização com Tailwind CSS, ícones de tecnologias com Simple Icons e controles com Lucide.
